# 🧬 Conway's Game of Life in C (Игра «Жизнь»)

> Консольная реализация легендарного клеточного автомата Джона Конвея на языке **C** с псевдографикой в реальном времени через **ncurses**.

---

## 🎮 О проекте

«Игра в жизнь» — это клеточный автомат с нулевым числом игроков, развитие которого полностью определяется его начальным состоянием. 

### Правила перехода поколений:
1. **Выживание:** любая живая клетка (`#`), имеющая 2 или 3 живых соседей, продолжает жить в следующем поколении.
2. **Рождение:** в любой мертвой клетке (`.`), рядом с которой ровно 3 живых соседа, зарождается жизнь.
3. **Смерть:** во всех остальных случаях клетка умирает от перенаселения (>3 соседей) или от одиночества (<2 соседей).

---

## ⚙️ Технические особенности реализации

- **Тороидальное поле (80 × 25):** границы игрового поля замкнуты сами на себя — правый край соединяется с левым, а верхний с нижним по формулам `(row + dr + HEIGHT) % HEIGHT` и `(col + dc + WIDTH) % WIDTH`.
- **Двойная буферизация:** расчет нового поколения происходит в отдельный буфер `nxt`, что гарантирует атомарную смену кадров без эффекта «гонок» состояний.
- **Разделение потоков ввода (`stdin` + `/dev/tty`):** начальное состояние считывается из файла через перенаправление ввода (`stdin`), а интерактивное управление с клавиатуры перехватывается напрямую через `/dev/tty` и функцию `newterm()` библиотеки `ncurses`.
- **Чистый структурный код по Дейкстре:** разделение на изолированные функции, отсутствие глобальных переменных в логике и отсутствие утечек памяти.

---

## ⌨️ Управление в реальном времени

| Клавиша | Действие |
| :--- | :--- |
| **`A` / `a`** | Увеличить скорость симуляции (уменьшить задержку на 100 мс) |
| **`Z` / `z`** | Уменьшить скорость симуляции (увеличить задержку на 100 мс) |
| **`Space`** (Пробел) | Завершить игру и выйти в терминал |

Диапазон задержки между поколениями: от **50 мс** (максимальная скорость) до **1000 мс** (1 кадр/сек).

## 🚀 Сборка и запуск

### Требования:
- Компилятор `gcc` или `clang`
- Библиотека `ncurses` (`libncurses-dev` / `ncurses`)

### 1. Компиляция проекта
```bash
make
```

### 2. Запуск со стартовыми паттернами
В репозитории подготовлены 5 классических конфигураций:

```bash
# 1. Глайдер (движущаяся фигура)
./game_of_life < glider.txt

# 2. Ружьё Госпера (генератор бесконечных глайдеров)
./game_of_life < glider_gun.txt

# 3. Мигалки (периодический осциллятор)
./game_of_life < blinkers.txt

# 4. Маяк (периодическая фигура)
./game_of_life < beacon.txt

# 5. Жаба (осциллятор периода 2)
./game_of_life < toad.txt
```
